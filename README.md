# CleanPress_public
Code snippets of a new CMS based on Symfony

### Editor.html.twig
Piece of code to enable the current section input to be displayed first, as saved in the database.

### MarkdownRenderer.php
Page updated to be able to render tables according to League\CommonMark doc. It does work.

League\CommonMark can be downloaded via:
```bash
composer require league/commonmark
```
